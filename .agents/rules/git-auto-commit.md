# Git Commit Rule

Whenever file changes/updates in `job-app-agent` are approved/accepted by the user, automatically commit and push the changes to the GitHub repository:
`https://github.com/Kushagra-Garg-27/Personal-Internship-Job-Application-Agent.git`

## Actions Required Upon File Change Approval:
1. Stage modified and new files: `git add .`
2. Commit with a clear, descriptive message summarizing the changes.
3. Push to `origin main` (or the default branch).
